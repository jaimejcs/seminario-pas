# Blackboard

Execute `python3 run.py` na raiz e selecione Blackboard. `engine.py` contém especialistas que só recebem o quadro compartilhado, publicam fatos e registram autoria. O controlador agenda observação, decisão e recomendação. EventExpert é registrado quando há evento esportivo. Inspecione rastro e JSON no painel. Regras comuns: `shared/traffic-rules.md`.
